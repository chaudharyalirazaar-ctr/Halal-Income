Backup & restore

A backup is a single .zip with everything: the full database (all users, investments, deposits, withdrawals, projects, referrals) plus every uploaded file (KYC documents, payment proofs). Download one regularly and keep it somewhere safe.

Download full backup

Restore from backup

Restoring replaces ALL current data on this site with whatever is in the file you upload. This cannot be undone from here — anything created since that backup was taken will be lost. (Your current data is auto-backed-up first as a safety net, but don't rely on that instead of taking your own regular backups.)

Two-factor authentication

Adds a second step to logging in on this account — after your password, you'll also need a 6-digit code from an authenticator app (Google Authenticator, Authy, 1Password, etc.). Strongly recommended for any admin account, since admins can approve deposits and withdrawals.

Team & permissions

Give trusted people just the access they need to help run the site — a KYC reviewer, a withdrawals approver, a project manager, or someone who can see everything but approve nothing. Check "Super admin" for full access instead (including managing everyone else's access, backups, and the audit log). Only super admins can see or use this section.
